## 📖 About this application

The addon-ez-bedrock-loader simplifies how you add custom content to your sandbox game. You often find mods or add-ons online, but installing them manually can feel difficult. This tool acts as a bridge between your web browser and your game. It handles the preparation and placement of files so you can focus on playing. You use a web-based workflow to select your add-ons, and the application does the heavy lifting.

## ⚙️ System Requirements

## 🛠️ Troubleshooting common issues

If the application fails to move your files, check these common items. First, verify that your game is closed while the loader processes files. If you run the game while moving files, conflicts might happen. Second, verify your internet connection. The loader fetches data from the web, and a weak signal might prevent the file list from loading.

If the loader cannot find your game, you can manually point the application to the folder where your game resides. Navigate to the Settings menu within the loader, then click Browse to select your folder. If you still see errors, restart your computer and try again. 

## 🌐 Local serving support

Advanced users might want to host their own add-on collections. The loader supports local serving, which means you can load files directly from a folder on your hard drive instead of the internet. This works well if you have a slow connection or if you want to test mods you created yourself. To enable this, go to the Advanced tab in the application and toggle the Local Serving option. Select the folder containing your files, and the loader will treat that folder as a source for new add-ons.

## 🧩 Deployment guidance

If you plan to share your own add-ons, you can package them for the loader. Create a folder with your files and a metadata file. The metadata file tells the loader what your add-on does. This allows other users to install your work with the same simple workflow you use. Place these files in a public repository to allow the loader to pull them automatically.
